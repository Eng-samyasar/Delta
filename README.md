# موقع شركة دلتا للتوريدات العمومية
### Delta General Supplies — Official Landing Page & Web Platform

صفحة هبوط تعريفية وتسويقية احترافية متكاملة لشركة **دلتا للتوريدات العمومية** بمحافظة كفر الشيخ، مصر. مصممة ومبرمجة بأحدث معايير الويب (HTML5 دلالي، CSS حديث، وVanilla JavaScript ES Modules) بهوية صناعية قوية مستخرجة رقمياً من لوجو الشركة، وخالية تماماً من أي إيموجي (اعتماد كامل على أيقونات SVG نظيفة)، ومتوافقة مع معايير السيو المحلي والأمان الصارم وسرعة التحميل الفائقة.

---

## 1. المميزات الرئيسية

- **هوية بصرية صناعية رصينة**: مستخرجة من ألوان اللوجو (الكحلي الصناعي `#1F2F3C`، الأصفر الذهبي `#F0C22E`، وخلفية الكانفاس الدافئة `#F6F4EF`) مع توظيف موتيف مثلث دلتا والشريط المائل.
- **بدون أي إيموجي على الإطلاق**: كافة الأيقونات (الهواتف، الواتساب، المعدات، الأقسام) بصيغة SVG خطية فائقة النقاء.
- **مصدر واحد موحد للبيانات (Single Source of Truth)**: جميع أرقام الأقسام، العناوين، مواعيد العمل، ومجالات التوريد يتم تعديلها من ملف واحد فقط (`assets/js/site-config.js`) وتنعكس آلياً على العرض، وروابط الاتصال، والواتساب، والـ Schema.org.
- **جدول التواصل المعتمد**: 4 أقسام تخصصية، مع عرض **رقمين في نفس الصف لكل قسم** (خدمة العملاء، التسويق، المبيعات، الإدارة) مع أرقام LTR بخط أحادي الخانة `tabular-nums`.
- **فهرس مجالات التوريد الـ 12**: استعراض منظم ومبوب بنمط الكتالوج الصناعي (01 إلى 12) مع زر "اطلب هذا المجال" الذي ينتقل للفورم ويحدد الصنف تلقائياً.
- **نموذج طلب عرض السعر محمي وآمن**:
  - فحص وتدقيق صيغة الموبايل المصري (`010, 011, 012, 015` متبوعة بـ 8 أرقام).
  - مصيدة روبوتات خفية (Honeypot) لحظر البوتات والسبام.
  - صمام أمان لمنع التكرار (Rate Limiting).
  - زر إرسال مباشر عبر **واتساب المبيعات** يُجهز رسالة منسقة تلقائياً ببيانات الطلب.
- **خريطة تفاعلية بنظام Click-to-Load**: تحمي سرعة الموقع وخصوصية الزوار، ولا تُحمّل Iframe الخريطة إلا بطلب المستخدم.
- **سيو محلي قوي (Local SEO)**:
  - H1 رئيسي وحيد مستهدف لكفر الشيخ والدلتا.
  - ترميز بيانات منظمة كامل (Schema.org JSON-LD) يضم: `Organization`، `WholesaleStore`، `ContactPoint` لكافة الأقسام، `OfferCatalog` للـ 12 مجالاً، و`FAQPage`.
  - ملفات `sitemap.xml` و`robots.txt` و`site.webmanifest`.
- **دروع أمان متكاملة (Security Headers)**: ملفات جاهزة للنشر الفوري تدعم CSP الصارم، HSTS، X-Frame-Options، ومنع التضمين، وسياسة أذونات الأجهزة.

## 3. كيفية تشغيل الموقع محلياً (Local Development)

الموقع مبني بنظام **Static-First متطور** ولا يحتاج إلى بيئات تثبيت معقدة. لتشغيله محلياً:

### الطريقة 1: عبر Python (موصى بها)
افتح التيرمينال داخل مجلد المشروع ونفّذ:
```bash
python -m http.server 8080
```
ثم افتح في متصفحك: `http://localhost:8080`

### الطريقة 2: عبر Node.js / npx
```bash
npx serve .
```

### الطريقة 3: عبر VS Code Live Server
اضغط كليك يمين على ملف `index.html` واختر **Open with Live Server**.

## 4. كيفية تعديل بيانات الشركة والأرقام (دليل المستخدم)

> [!IMPORTANT]
> **ممنوع كتابة الأرقام أو تعديلها في أكثر من مكان!**
> كافة أرقام الهواتف، وأقسام الاتصال، والبريد، والعنوان، ومجالات التوريد مجمعة في ملف واحد فقط:
> **`assets/js/site-config.js`**

### لتغيير أرقام الهواتف:
افتح `assets/js/site-config.js` وتوجه إلى مصفوفة `departments`:
```javascript
{
  id: 'customer-service',
  name: 'خدمة العملاء',
  numbers: [
    {
      raw: '01012345601',             // اكتب رقمك الفعلي هنا
      display: '010 1234 5601',       // الشكل التنسيقي الذي يظهر في الموقع
      label: 'خدمة العملاء - الخط الأول'
    },
    {
      raw: '01112345602',
      display: '011 1234 5602',
      label: 'خدمة العملاء - الخط الثاني'
    }
  ]
}
```
عند تعديل أي رقم، سيتحدث تلقائياً:
1. الرقم المعروض في جدول التواصل.
2. رابط الاتصال الهاتفي `tel:`.
3. رابط محادثة الواتساب المباشرة `wa.me`.
4. كود الـ Schema.org لمحركات البحث.

### لتغيير العنوان أو مواعيد العمل:
عدل كائن `company.headquarters` وكائن `company.workingHours` في نفس الملف.

## 5. دليل النشر على خوادم الاستضافة (Deployment Guide)

المشروع مزود بملفات الضبط الجاهزة لأشهر منصات الاستضافة:

### أ) النشر على Cloudflare Pages / Netlify (الأفضل أداءً ومجاني)
1. ارفع المشروع إلى مستودع GitHub أو قم بسحب المجلد مباشرة إلى Cloudflare Pages / Netlify.
2. ملف `_headers` الموجود في الجذر سيقوم تلقائياً بتطبيق شهادة SSL، HSTS، ورؤوس الأمان وسياسة CSP والتخزين المؤقت للأصول.

### ب) النشر على Vercel
1. قم بربط المستودع بـ Vercel.
2. سيتعرف Vercel تلقائياً على ملف `vercel.json` ويُطبّق كافة قواعد الأمان والتخزين المؤقت للأصول.

### ج) النشر على الاستضافات العادية (cPanel / Apache / LiteSpeed)
1. ارفع محتويات المجلد بالكامل إلى مجلد `public_html`.
2. ملف `.htaccess` المرفق سيقوم بتحويل الروابط إلى HTTPS تلقائياً وتفعيل رؤوس الأمان.

### د) النشر على VPS خادم Nginx
1. انسخ محتويات ملف `nginx.conf` المرفق داخل مجلد إعدادات السيرفر `/etc/nginx/sites-available/deltasupplies`.
2. قم بتحديث مسار المجلد `root` واسم النطاق، ثم أعد تشغيل Nginx:
   ```bash
   sudo systemctl reload nginx
   ```

## 6. قائمة المهام قبل الإطلاق النهائي (Pre-Launch Checklist)

- [ ] **أرقام الهواتف**: استبدال الأرقام المؤقتة بالأرقام الفعلية للشركة في `assets/js/site-config.js`.
- [ ] **البريد الإلكتروني**: تحديث البريد الإلكتروني الرسمي للتعاقدات.
- [ ] **ربط النطاق (Domain Name)**: توجيه دومين `deltasupplies-eg.com` (أو الدومين الفعلي للشركة) إلى الاستضافة.
- [ ] **Google Business Profile**: مطابقة بيانات NAP (الاسم، العنوان، وأرقام التليفونات) مع ملف Google Business لشركة دلتا بكفر الشيخ لتعزيز الظهور في خرائط جوجل والبحث المحلي.
- [ ] **خريطة جوجل**: استبدال رابط الـ Embed في `headquarters.mapEmbedUrl` في حال الرغبة بتثبيت موقع فرع محدد بدقة.
- [ ] **إرسال خريطة الموقع**: تقديم رابط `https://your-domain.com/sitemap.xml` في Google Search Console.
